## How to Run

**Prerequisites:** Java 17+ installed

```bash
# Compile a single file
javac 01_Java_Basics/HelloWorld.java

# Run it
java -cp 01_Java_Basics HelloWorld

# Or compile and run from the file's directory
cd 01_Java_Basics
javac HelloWorld.java
java HelloWorld
```
